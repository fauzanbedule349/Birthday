BIRTHDAY WEBSITE

1. Open index.html in your browser.
2. Default password: birthday123
3. Edit CONFIG in script.js to change:
   - password
   - name
   - birthday message
   - music path
   - gallery photos
   - timeline
   - wishes
4. Replace assets/images/photo1.jpg ... photo6.jpg with your real photos.
5. Replace assets/music/birthday-song.mp3 with your own MP3.

The included MP3 is only a generated ambient demo tone so the music button can be tested.
No external copyrighted music is used.
